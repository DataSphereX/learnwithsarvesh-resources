Hints:
CTE -> Common Table Expression: a named sub-query defined with WITH ... AS ( ... ),
       used like a temporary table inside one query.


Type		Means
----		-----
passthrough	copied as-is, no computation
aggregate	computed via SUM/COUNT/AVG/etc. over rows
derived		computed via some expression/formula
label		a computed boolean/categorical flag
